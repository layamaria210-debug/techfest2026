\# TechFest 2026



A full-stack web application developed for TechFest 2026 using React, Node.js, Express.js, and MongoDB.



\## Project Overview



TechFest 2026 is a web application that provides information about technical and cultural events and allows students to browse events and register for them.



The project contains an original HTML/CSS/JavaScript implementation as well as a React-based frontend connected to a Node.js and Express.js backend.

\## Features



\- Home page with TechFest information.

\- Event listing and event search.

\- Event category filtering.

\- Student registration.

\- User authentication.

\- Event registration management.

\- Seat availability tracking.

\- Gallery section.

\- Contact page.

\- Light and dark theme support.

\- REST API integration.

\- MongoDB database integration.
